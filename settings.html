设置与部署

配置 GitHub 连接后即可在手机和电脑上随时录入；访客通过链接只读查看

三步上线（约5分钟）

1. 注册/登录 GitHub，打开 生成令牌页面，勾选 repo，生成并复制 ghp_...
2. 把令牌填到下方并保存（只存在你自己的设备上，不会上传）
3. 在本文件夹打开 PowerShell，运行 node deploy.js，按提示完成；脚本会自动建仓库、传文件、开启 GitHub Pages
之后把生成的 https://用户名.github.io/longcheng-crm/ 发给同事即可，他们只能查看。
