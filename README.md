# 龙城·营峰天境 · 客户归档与跟进系统

手机/电脑均可使用的客户管理网站，部署在 **GitHub Pages**：访客凭链接只读查看，管理员（你）在已保存令牌的设备上可随时录入、修改。

## 一、首次部署（约 5 分钟，只需一次）

1. 注册并登录 GitHub，打开令牌生成页：
   https://github.com/settings/tokens/new?scopes=repo&description=longcheng-crm
   勾选 **repo**，点 Generate，复制 `ghp_...`。
2. 在本文件夹地址栏输入 `powershell` 回车，运行：
   ```powershell
   node deploy.js
   ```
   按提示粘贴令牌。脚本会自动：创建仓库 → 上传全部文件 → 开启 GitHub Pages。
3. 部署完成后得到地址：
   ```
   https://你的用户名.github.io/longcheng-crm/
   ```
   用手机浏览器打开，建议"添加到主屏幕"，像 App 一样使用。

> 令牌只在你自己设备的浏览器和部署时使用，网站代码和访客都看不到。

## 二、解锁手机/电脑上的录入权限

1. 打开网站 → 右上角齿轮（设置）。
2. 填写 GitHub 用户名、仓库名（longcheng-crm）、令牌，点"测试连接"成功后保存。
3. 页面顶部变为"可编辑"，即可录入。访客设备不填令牌 = 永远只读。

## 三、日常使用

| 页面 | 用途 |
| --- | --- |
| 驾驶舱 | 今日/累计收集、转换、到访、逼定、成交 KPI；趋势图、阶段漏斗、信息/到访擂台、人员战力榜、待跟进与高意向客户 |
| 报备录入 | **直接粘贴微信报备消息**，自动识别字段（信息/转换/首访/再访，支持多条），核对后一键归档；也可手动填写 |
| 客户档案 | 全部客户，搜索与按阶段/等级筛选；客户详情含画像标签、跟进时间轴、痛点跟踪、录音、快捷操作（沟通/逼定/成交/变更阶段） |
| 日报表 | 复刻《意向客户统计及分析日报表》，数字由报备自动统计，今日数据可手动修正；管理逼定布局清单与注意事项 |
| 录音归档 | 上传音频（20MB 内）或粘贴飞书云盘外链，自动挂到客户时间轴，可附摘要 |

## 四、数据如何自动流转

```
信息报备 → 转换报备 → 首访报备 → 再访报备 → 逼定 → 成交
 新线索    已邀约     方案沟通    再访跟进    逼定中   已成交
```
- 按信息编码/电话/微信/姓名自动匹配客户，无需重复建档。
- 画像、意向等级、到访次数随报备自动更新。
- 再访"最终结果"为成交/流失时自动归档阶段。

## 五、数据与备份

- 全部数据为仓库 `data/` 下的 4 个 JSON 文件，随每次录入通过 GitHub API 更新，可在 GitHub 网页查看历史版本、随时回滚。
- 设置页支持"导出全部数据 / 导入"，换设备时迁移用。
- 飞书多维表格链接可填入设置页，驾驶舱出现入口，两套工具并行不冲突。

## 六、常见问题

- **双击打开网页提示本地预览？** 属正常，部署后用 https 链接即云端共享；本地预览数据仅存该浏览器。
- **录音上传失败？** 文件超过 25MB 或令牌未勾选 repo 权限；改用飞书外链。
- **想改仓库名？** `node deploy.js 令牌 新仓库名`，并在设置页同步修改。
- **令牌泄露怎么办？** 到 GitHub Settings → Developer settings → Tokens 删除即失效，再生成新令牌。
